Commercial Refund Policy

Clear on-chain settlement rules for commercial Team (99 USDC) and Enterprise (499 USDC) licenses of evalshield-copilot on Base Mainnet.

1. Final Sale Upon Entitlement Issuance

Because commercial licenses for #6 evalshield-copilot are cryptographically signed Ed25519 entitlements (EVALSHIELD-PRO-v1 token + evalshield-copilot-entitlement.json + HTML certificate) delivered immediately after on-chain Base Mainnet USDC verification, all completed entitlement issuances are final sale and non-refundable. Solo Personal use (0 USDC) and all MIT tools (#1–#5, #7) require no payment.

2. Accidental Duplicate or Wrong-Amount Base USDC Transfers

If you accidentally send a duplicate Base Mainnet USDC transaction or transfer an incorrect USDC amount that fails automatic license issuance, ApexHive Labs will review the claim within 7 days of transaction confirmation and return verified excess/erroneous Base USDC minus network gas fees.

To request review, email apexhive.hq@proton.me with your Base Mainnet transaction hash (txHash), sending wallet address, and a signed message if requested to verify sender ownership.
