How slimmcp-proxy Works Across stdio, HTTP & SSE

Pure Node.js ≥24.0.0 using built-in node:sqlite and node:crypto — zero Docker, zero node-gyp, zero external embedding APIs.

1. discover_tools

Deterministic BM25 search across local stdio, Streamable-HTTP, and SSE upstreams returning compact tool summaries.

2. inspect_tool_schema

Lazy-loads the full JSON schema for only the single tool you intend to invoke — keeping unused schemas out of prompt context.

3. invoke_tool

Masks common secret patterns (AWS keys, GitHub PATs, Stripe keys, OpenAI tokens, PEM keys, JWTs), enforces free MIT RBAC/budget rules, and proxies execution.

Verified Quick Start (npm npx & GitHub Source)

Install via npm for Node.js ≥24 or clone any repository directly from GitHub:

# 1. Run slimmcp-proxy (100% Free MIT):
npx -y slimmcp-proxy --help
npx -y slimmcp-proxy serve --config /path/to/mcp-servers.json

# 2. Run mcp-doctor static MCP CI linter (100% Free MIT):
npx -y apexhive-mcp-doctor status

# 3. Clone & run verified 60-tool benchmark from source:
git clone https://github.com/apexhive-hq/slimmcp-proxy.git
cd slimmcp-proxy/cli
pnpm install --ignore-scripts
pnpm run typecheck && pnpm test && pnpm run benchmark
