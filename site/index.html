How slimmcp-proxy Works Across stdio, HTTP & SSE

Built on Node.js ≥22.13 LTS with built-in node:sqlite and node:crypto — no Docker, native addons, or external embedding APIs required.

1. discover_tools

Deterministic BM25 search across local stdio, Streamable-HTTP, and SSE upstreams returning compact tool summaries.

2. inspect_tool_schema

Lazy-loads the full JSON schema for only the single tool you intend to invoke — keeping unused schemas out of prompt context.

3. invoke_tool

Fails closed on deep payloads (>24 depth), masks sensitive JSON keys and secrets, enforces deny-overrides RBAC/budget rules, and isolates child env variables.

Quick Start (npm npx & Source)

Run our CLI tools directly with npx or clone any repository from GitHub:

# 1. Run slimmcp-proxy (MIT, Node >=22.13 LTS):
npx -y slimmcp-proxy --help
npx -y slimmcp-proxy serve --config /path/to/mcp-servers.json

# 2. Run mcp-doctor static MCP CI linter (MIT, Node >=20 LTS):
npx -y apexhive-mcp-doctor status

# 3. Clone & run the 60-tool benchmark from source:
git clone https://github.com/apexhive-hq/slimmcp-proxy.git
cd slimmcp-proxy/cli
pnpm install --ignore-scripts
pnpm run typecheck && pnpm test && pnpm run benchmark

Example mcp.json (npm npx):

{
  "mcpServers": {
    "slimmcp": {
      "command": "npx",
      "args": ["-y", "slimmcp-proxy", "serve", "--config", "/path/to/mcp-servers.json"]
    }
  }
}
