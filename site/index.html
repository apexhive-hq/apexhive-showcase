How slimmcp-proxy Works Across stdio, HTTP & SSE

Pure Node.js ≥22.13 LTS using built-in node:sqlite and node:crypto — zero Docker required, zero node-gyp, zero external embedding APIs.

1. discover_tools

Deterministic BM25 search across local stdio, Streamable-HTTP, and SSE upstreams returning compact tool summaries.

2. inspect_tool_schema

Lazy-loads the full JSON schema for only the single tool you intend to invoke — keeping unused schemas out of prompt context.

3. invoke_tool

Fails closed on deep payloads (>24 depth), masks sensitive JSON keys and secrets, enforces deny-overrides RBAC/budget rules, and isolates child env variables.
